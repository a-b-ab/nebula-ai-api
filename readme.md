# 星云AI
一个基于 Go 的多模态 AI 服务平台，支持：
- 文生图（Text-to-Image）
- 图生图（Image-to-Image）
- 文生文（Text-to-Text）
- 图生文（Image-to-Text）
采用微服务架构，支持任务异步调度与分布式部署，面向 AI 应用场景的完整工程实践项目。

## 项目目标
构建一个可扩展的 AI 推理服务平台
实践微服务 + 容器化 + 云原生架构
打造完整的 AIGC 工程体系
沉淀 Go 后端高并发与分布式开发经验

## 技术栈
后端
Go + Gin（REST API）
MySQL（业务数据存储）
Redis（缓存 / 任务状态 / 分布式锁）
RabbitMQ（异步任务队列）
Docker + Kubernetes（容器化部署）
Prometheus + Grafana（监控告警）

前端
React + TypeScript（规划中）

## 核心功能
1. AI 推理任务系统
支持异步提交推理任务
基于 MQ 解耦请求与推理服务
Redis 管理任务状态与进度
支持失败重试与幂等控制

2. 多模态模型管理
模型版本管理
动态加载 / 切换模型
推理资源调度

3. 用户与权限系统
JWT 鉴权
Token 管理
API 限流

4. 分布式部署
多实例负载均衡
K8s 自动扩缩容
容器化 GPU 推理服务

## 可观测性
- Prometheus：服务指标采集
- Grafana：性能监控面板
- ELK（规划中）：日志分析系统
