# 当前项目接口

本文以当前后端路由和处理函数为准。所有路径均以 `/api` 开头；本地默认端口为 `8080`，可通过 `SERVER_PORT` 修改。除健康检查外，接口成功响应统一为 HTTP 200：

```json
{"code":0,"message":"成功","data":{}}
```

失败响应格式为 `{"code":HTTP状态码,"message":"错误信息"}`，通常使用 400（参数错误）、404（详情不存在）或 500（服务/数据库错误）。`DELETE` 成功时省略 `data`。目前路由没有配置认证中间件。

## 文章接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/api/articles` | 创建文章 |
| GET | `/api/articles` | 分页查询文章，可按状态筛选 |
| GET | `/api/articles/:id` | 查询文章详情 |
| PUT | `/api/articles/:id` | 更新文章字段 |
| DELETE | `/api/articles/:id` | 删除文章 |
| PUT | `/api/articles/:id/status` | 更新文章状态 |
| POST | `/api/articles/:id/platforms` | 记录一个发布平台 |
| POST | `/api/articles/:id/optimize` | 创建文章 AI 优化任务 |

所有 `:id` 都是十进制无符号整数；无法解析时返回 400。文章状态以数字表示：`0` 草稿、`1` 已优化、`2` 已发布。

### 创建文章

`POST /api/articles`，请求体为 JSON：

```json
{"title":"示例标题","content":"# 正文","summary":"摘要","tags":"Go,AI"}
```

`title`、`content` 必填，`summary`、`tags` 可选；`tags` 当前是字符串，没有数组结构。成功时 `data` 是创建后的文章对象；新文章的 `status` 为 `0`、`ai_optimized` 为 `false`、`publish_platform` 为空字符串。

### 文章列表与详情

`GET /api/articles?page=1&page_size=10&status=0`：

| 查询参数 | 说明 |
| --- | --- |
| `page` | 默认 1；小于 1 时使用 1 |
| `page_size` | 默认 10；小于 1 时使用 10，大于 100 时使用 100 |
| `status` | 可选；提供后按状态精确筛选 |

结果按 `created_at` 降序排列。`data` 是分页对象：

```json
{"code":0,"message":"成功","data":{"data":[],"total":0,"page":1,"page_size":10}}
```

查询组件虽然读取 `keyword`、`sort_by`、`sort_order`，文章列表的服务层目前没有使用它们；不要依赖这些参数进行搜索或排序。`status` 当前按整数解析，非法字符串会被解析为 `0`，且没有状态范围校验。

`GET /api/articles/:id` 成功时 `data` 是文章对象，文章不存在时返回 404。文章对象字段为 `id`、`title`、`content`、`summary`、`tags`、`ai_optimized`、`publish_platform`、`status`、`created_at`、`updated_at`。

### 更新和删除

`PUT /api/articles/:id` 接受以下可选字段；只修改请求中提供的字段，成功时返回更新后的文章对象：

```json
{"title":"新标题","content":"新正文","summary":"新摘要","tags":"Go,设计","publish_platform":"juejin,csdn","status":1}
```

此接口目前不校验 `status` 是否属于 0～2，也允许直接覆盖 `publish_platform` 字符串。`DELETE /api/articles/:id` 删除文章，成功时返回统一成功响应且不含 `data`。更新或删除不存在的文章，当前处理函数返回 500。

### 更新状态和记录发布平台

- `PUT /api/articles/:id/status`：请求体 `{"status":2}`，成功时 `data.message` 为 `状态更新成功`。请求体声明的范围是 0～2，但当前 `required` 校验会拒绝整数 `0`；若要设为草稿，目前可使用普通更新接口。此接口没有检查文章是否存在，数据库更新 0 行也可能返回成功。
- `POST /api/articles/:id/platforms`：请求体 `{"platform":"csdn"}`，成功时 `data.message` 为 `平台添加成功`。平台名必填；服务层将平台名追加到逗号分隔的 `publish_platform` 字符串，已有相同平台时不重复追加。文章不存在时当前返回 500。此接口只记录平台，不执行实际发布，也不自动修改 `status`。

### AI 优化任务

`POST /api/articles/:id/optimize` 不需要请求体，成功时 `data` 为任务对象。文章不存在时返回 400。若该文章已有 `pending` 或 `processing` 的优化任务，会返回已有任务；否则创建 `pending` 任务。任务由后台 worker 异步处理，接口返回不代表优化已完成。当前启动配置使用模拟优化器；任务完成后才会更新文章内容、`ai_optimized=true` 和 `status=1`。

## 相关任务接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/tasks` | 分页查询任务；可用 `article_id` 筛选 |
| GET | `/api/tasks/:id` | 查询任务详情；不存在时返回 404 |

任务列表使用同样的 `page`、`page_size` 规则，按 `created_at` 降序返回同样的分页对象。`article_id` 应为十进制无符号整数。任务对象包含 `id`、`type`、`status`、`article_id`、`payload`、`result`、`error`、`started_at`、`finished_at`、`created_at`、`updated_at`、`max_retries`；其中 `payload`、`result` 为 `nil` 时省略。文章优化任务的 `type` 为 `article_optimize`，状态可能为 `pending`、`processing`、`completed`、`failed`。当前任务列表处理函数在 `article_id` 解析失败或查询失败后缺少 `return`，可能在错误响应后继续写成功响应；调用方应传合法参数。

## 其他项目接口

| 方法 | 路径 | 请求 | 成功响应的 `data` |
| --- | --- | --- | --- |
| POST | `/api/markdown/convert/csdn` | JSON：`markdown` 必填；`title` 可选；`include_wrapper` 可选，默认 `true` | `format`、`html`，以及非空时的 `title` 和启用包装时的 `wrapped_html` |
| GET | `/api/health` | 无 | 不使用统一响应结构，直接返回 `{"status":"ok"}` |

Markdown 转换接口将 Markdown 转成 CSDN 用 HTML；内容为空或只有空白时返回 400。`include_wrapper=true` 时额外返回带 `content_views` 容器的 HTML。
